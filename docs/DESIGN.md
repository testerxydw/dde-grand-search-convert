# 设计文档 · DDE 全局搜索转换插件

> 本文档基于 deepin-skills（`dde-grand-search` 插件开发指南 V1.0）与官方计算器示例设计。

## 1. 背景与目标

deepin 社区「10 亿 Token 奖池」插件大赛新增方向：全局搜索插件。目前 0 人提交，
属于蓝海。本插件让用户在 DDE 全局搜索栏直接完成**各类高频轻量查询**，覆盖多类人群：

- 办公党：日期差、倒数日、颜色 HEX/RGB 互转
- 学生/科研：单位换算、科学计算器、汇率
- 程序员：进制转换、Base64、URL、哈希、ASCII、时间戳
- 设计师：颜色 HEX/RGB/HSL 互转

参考：macOS 聚焦搜索（单位/汇率/计算/换算能力强）、Ubuntu Calculator（表达式与进制）、
GNOME 无同类聚合插件、deepin 生态空白。

## 3. 解析策略（QueryParser）

| 输入样例 | 判定类型 | 提取 |
|---------|---------|------|
| `100usd` / `$50` / `100美元` | currency | amount=100, from=USD |
| `100 usd to cny` / `100usd=?cny` | currency | amount, from, to |
| `12inch` / `3km` / `1kg=?斤` | unit | value, fromUnit, [toUnit] |
| `100F` / `37C` / `32f to c` | unit(temp) | value, scale |
| `北京时间` / `tokyo now` / `纽约时间` | time | city/timezone |
| `12*8+sqrt(16)` / `255 to hex` / `0xff+1` | calc | 表达式文本 |
| `base64 encode hello` / `md5 x` / `时间戳` | program | 关键词 + 内容 |
| `距 2027-01-01 还有几天` / `2025-01-01 到 2025-12-31` | datetime | 日期串 |
| `#ff8800` / `rgb(255,136,0)` / `hsl(32,100%,50%)` | color | 颜色串 |

解析优先级（高→低）：货币符号/代码 → 温度后缀 C/F → 单位词 → 城市名
→ 颜色串 → 程序员工具关键词 → 日期形态/关键词 → 计算器表达式 → 无匹配返回空。
无匹配则返回空结果（不影响其他搜索项）。

## 4. 模块划分

- `convertsearch.h/.cpp`：DBus 业务主体，实现 search/stop/action。
- `queryparser.h/.cpp`：正则解析与类型判定（含各业务关键词表）。
- `providers/currencyprovider.h/.cpp`：汇率（QNetworkAccessManager 联网 + QSettings 缓存 + 静态表降级）。
- `providers/unitprovider.h/.cpp`：单位换算表与计算。
- `providers/timeprovider.h/.cpp`：城市→IANA 时区映射与当前时间。
- `providers/calcprovider.h/.cpp`：安全表达式求值器（递归下降，无 eval）。
- `providers/programprovider.h/.cpp`：Base64/URL/哈希/ASCII/时间戳。
- `providers/datetimeprovider.h/.cpp`：日期差/倒数日/今天。
- `providers/colorprovider.h/.cpp`：HEX/RGB/HSL 互转。
- `resultbuilder.h/.cpp`：组装 V1.0 JSON。
- `searchpluginadaptor.h/.cpp`：由官方 XML 经 `qdbusxml2cpp` 生成的 Adaptor。
- `main.cpp`：注册 DBus 服务。

## 5. 关键约束（来自协议）

- 每组最多 100 项；`item`/`name`/`type` 必填且非空。
- Search 必须可中断（Stop 调用后尽快返回）；本插件为同步本地计算，stop 仅清理缓存任务。
- InterfaceVersion 固定 `1.0`，与 conf 一致。
- 25 秒超时：汇率联网需设超时与缓存，避免阻塞。

## 6. 网络与隐私

- 汇率联网仅请求公开只读 API（如 exchangerate.host / frankfurter.app），不收集用户数据。
- 失败自动降级到内置静态汇率，保证离线可用。
- 单位、时间、计算器、程序员工具（Base64/URL/哈希/ASCII/时间戳）、日期、颜色
  **全部本地计算，零网络依赖**，离线可用且不涉及隐私上传。
